Яаж ажиллуулах вэ?

  1. Энэ ZIP-ийг GitHub repository-д upload хийнэ.
  2. Settings → Pages → Deploy from a branch → main / root гэж сонгоно.
  3. Actions tab-д Paper Trading Scanner workflow-ийг идэвхжүүлнэ.
  4. Actions → Paper Trading Scanner → Run workflow дарж эхний удаа гараар ажиллуулж болно.

GitHub Actions-ийн хуваарьт ажиллалт яг тогтмол цагт биелэх баталгаа байхгүй. GitHub Pages зөвхөн dashboard харуулна; сканнерийг Actions ажиллуулна.

Энэ бол туршилтын prototype. API хязгаарлалт, дутуу metadata, price impact, honeypot зэрэг бүх эрсдэлийг бүрэн илрүүлэхгүй. Ашиг олох амлалт биш.
